# Site do Instituto Società + revista QuotaParte

Site em Vue 3 + Vite. O conteúdo (textos, membros, notícias, edições…) fica em `src/content/*.json` e é editado
pelo painel em `/admin`, sem programação.

- **Publicar e editar sem depender de ninguém:** veja o [GUIA-PUBLICACAO.md](GUIA-PUBLICACAO.md).
- **Desenvolvimento:** `npm install`, depois `npm run dev`.
- **Gerar a versão de produção:** `npm run build` (converte as imagens para WebP e gera a pasta `dist`).
